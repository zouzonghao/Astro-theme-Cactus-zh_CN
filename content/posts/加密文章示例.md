这是一篇加密文章。页面构建时，正文已被 AES-256-GCM 加密成密文写进 `data-encrypted` 属性，静态 HTML 里没有任何明文；输入正确密码后，浏览器会在本地完成解密并渲染。

## 二级标题一

这里可以验证普通段落、**加粗**、*斜体*、[链接](https://example.com)以及行内代码 `npm run build` 在解密后是否正常渲染。

### 三级标题

目录（TOC）没有在服务端渲染——否则标题结构会泄露内容——而是解密后由脚本从下面的标题动态重建。

## 二级标题二

代码块（expressive-code）也能正常工作：

```ts
function greet(name: string): string {
	return `你好，${name}！`;
}
```

> 引用块同样是密文的一部分。

## 数学公式

行内公式 $E = mc^2$ 与化学方程式在解密后同样正常渲染：

$$
\ce{2H2 + O2 -> 2H2O}
$$
